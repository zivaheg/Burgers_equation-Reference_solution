# Viscous Burgers Equation

MATLAB project for computing a reference numerical solution of the one-dimensional viscous Burgers equation using finite differences and time integration.

## Running the project

Open the project directory in MATLAB and run:

```matlab
data = run_burgers_project();
```

Generated numerical results, plots, and the animation are saved in `results_vse/`. The project report is available as `report_final.pdf`.
